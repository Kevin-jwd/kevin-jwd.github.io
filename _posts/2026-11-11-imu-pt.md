무릎 위아래에 부착한 IMU 4개의 움직임을 수집해 Unity 모델과 연동했습니다.

| 기간 | 참여 인원 | 구분 |
| --- | --- | --- |
| — | — | 졸업작품 |

## 프로젝트 개요

각 무릎의 위아래에 IMU를 부착해 움직임을 수집하고 가정에서 운동 자세를 확인할 수 있도록 구성한 Personal Training 시스템입니다. 2024 한국통신학회 학부 우수논문 장려상을 수상했습니다.

## 담당 역할

IMU 센서 데이터 수집과 보정·자세 추정, ESP32에서 서버·Unity로 이어지는 데이터 전달에 참여했습니다.

> 원본 코드의 형상관리가 되어 있지 않아 자세 계산과 센서 융합의 세부 알고리즘은 추가 확인이 필요합니다. 이 문서는 확인된 시스템 구성 중심으로 정리합니다.
{: .prompt-info }

## 시스템 구조

| 순서 | 구성 요소 |
| --- | --- |
| 1 | LSM9DS1 센서 4개 |
| 2 | I2C MUX / ESP32 |
| 3 | 로컬 서버 |
| 4 | Unity 모델 |

## 구현 내용

### 센서 배치

각 무릎의 위아래에 센서 2개씩, 총 4개를 배치합니다.

### 다중 센서 수집

I2C 멀티플렉서를 통해 센서 데이터를 ESP32로 수집합니다.

### 데이터 전달

ESP32 → UDP 로컬 서버 → TCP Unity 구조로 데이터를 전달합니다.

### 모델 연동

수집한 움직임 데이터를 Unity 모델과 연결합니다.

## 핀맵·통신 규격

| 연결 대상 | 인터페이스 | 용도 |
| --- | --- | --- |
| LSM9DS1 ↔ MUX ↔ ESP32 | I2C | 다중 IMU 데이터 수집 |
| ESP32 → 로컬 서버 | UDP | 센서 데이터 전송 |
| 로컬 서버 → Unity | TCP | 모델 연동 데이터 전달 |

상세 핀 번호와 전압 조건은 최종 회로·배선 확인 후 추가합니다.

## 트러블슈팅

문제 발생 당시의 증상과 점검 과정, 수정 내용 및 확인 결과를 정리해 추가할 예정입니다.

## 검증·시연

수상·발표 자료와 센서 구성을 중심으로 프로젝트를 정리합니다. 자세 추정 방식, 보정 절차와 오차 수치는 원본 자료를 확인한 뒤 구체화할 예정입니다.

## 참고 자료

발표자료와 논문 자료를 확인한 뒤 연결할 예정입니다.
