## 프로젝트 개요

온도 센서, LCD, 모터와 입력 장치를 연결한 스마트 선풍기 프로젝트입니다. 이 문서는 그중 직접 담당한 BMP180 온도 센서와 LCD1602 커널 드라이버를 중심으로 설명합니다.

## 담당 역할

BMP180 온도 측정·보정과 LCD1602 출력 드라이버를 담당했습니다. 사용자 프로그램이 문자 장치 인터페이스로 센서와 LCD에 접근할 수 있도록 구성했습니다.

> 모터·서보·입력 장치 및 사용자 앱 전체는 팀 시스템의 구성 요소이며, 이 문서의 개인 구현 범위와 구분합니다.
{: .prompt-info }

## 시스템 구조

| 순서 | 구성 요소 |
| --- | --- |
| 1 | 사용자 프로그램 |
| 2 | 문자 장치 인터페이스 |
| 3 | 센서·LCD 드라이버 |
| 4 | I2C 장치 |

## 구현 내용

### BMP180 온도 측정

센서 보정 계수와 변환 완료 상태를 반영해 온도를 읽습니다.

### LCD 부분 갱신

pwrite()로 원하는 위치의 문자를 갱신합니다.

### LCD 제어

ioctl()로 화면과 백라이트를 제어합니다.

### 장치 등록

Device Tree로 I2C 장치와 드라이버를 연결합니다.

## 핀맵·통신 규격

| 연결 대상 | 인터페이스 | 용도 |
| --- | --- | --- |
| BMP180 | I2C | 온도 측정 및 센서 보정 계수 읽기 |
| LCD1602 + I2C 백팩 | I2C | 문자 출력·화면·백라이트 제어 |
| 사용자 공간 | 문자 장치 | 온도 읽기, pwrite(), ioctl() |

상세 핀 번호와 전압 조건은 최종 회로·배선 확인 후 추가합니다.

## 트러블슈팅

### LCD가 정상 출력되지 않는 문제

| 구분 | 내용 |
| --- | --- |
| 증상 | LCD 초기화와 문자 출력이 정상적으로 이루어지지 않았습니다. |
| 원인 분석 | I2C 버스 속도와 LCD 백팩의 지원 속도를 대조했습니다. |
| 조치 | LCD를 400kHz 버스에서 100kHz 버스로 분리하고 배선과 Device Tree를 변경했습니다. |
| 확인 결과 | 변경 후 LCD 초기화와 문자 출력을 확인했습니다. |

## 검증·시연

센서 읽기와 LCD 제어의 인터페이스를 기준으로 구현을 정리했습니다. 반복 동작·통합 시연의 상세 결과는 시험 기록과 함께 추가할 예정입니다.
