## 프로젝트 개요

초음파 센서로 장애물에 대응하는 자율주행과 Bluetooth 명령 기반 수동 주행을 지원하는 RC Car입니다. 각자 차량을 구현하고 발표를 함께 진행했습니다.

## 담당 역할

개별 차량의 센서 수집, 거리 데이터 처리, 주행 제어 및 FND 상태 표시 전반을 구현했습니다.

> 공개 AVR 실습 저장소의 코드와 최종 로컬 자율주행 소스는 버전이 다릅니다. 아래 저장소 링크는 관련 실습 코드로 구분합니다.
{: .prompt-info }

## 시스템 구조

| 순서 | 구성 요소 |
| --- | --- |
| 1 | 초음파 센서 3개 |
| 2 | Echo 시간 측정·필터 |
| 3 | 주행 상태 판단 |
| 4 | PWM 모터 제어 |

## 구현 내용

### 거리 측정

타이머·외부 인터럽트로 초음파 Echo 시간을 측정합니다.

### 데이터 처리

칼만 필터를 적용해 거리 데이터를 처리합니다.

### 주행 제어

장애물 대응 주행 로직과 PWM 모터 제어를 연결합니다.

### 수동 주행·상태 표시

Bluetooth UART 명령을 처리하고 FND로 상태를 표시합니다.

## 핀맵·통신 규격

| 연결 대상 | 인터페이스 | 용도 |
| --- | --- | --- |
| 초음파 센서 3개 | Trigger / Echo | 장애물 거리 측정 |
| Bluetooth 모듈 | UART | 수동 주행 명령 수신 |
| 모터 드라이버 | PWM / GPIO | 속도·방향 제어 |
| FND | GPIO | 상태 표시 |

상세 핀 번호와 전압 조건은 최종 회로·배선 확인 후 추가합니다.

## 트러블슈팅

문제 발생 당시의 증상과 점검 과정, 수정 내용 및 확인 결과를 정리해 추가할 예정입니다.

## 검증·시연

최종 로컬 코드에서 자율주행, 칼만 필터, FND와 모드 구현을 확인했습니다. 코드 존재와 실제 장치의 시험 결과는 구분하며, 시연 영상과 주행 조건을 추가할 예정입니다.
