초음파 거리 측정과 장애물 대응 주행, Bluetooth 수동 제어를 연결했습니다.

| 기간 | 참여 인원 | 구분 |
| --- | --- | --- |
| 2026.06.22 ~ 2026.06.25 | 1명 (개별 차량) | 개인 구현 · 공동 발표 |

## 프로젝트 개요

- 3방향 초음파 센서로 주변 거리를 측정하여 주행 방향을 결정합니다.
- Bluetooth로 수동 조작도 가능합니다.
- 주행 상태와 시간·동작 횟수를 두 개의 FND에 출력합니다.

## 담당 역할

개별 차량의 센서 수집, 거리 데이터 처리, 주행 제어 및 FND 상태 표시 전반을 구현했습니다.

> 공개 AVR 실습 저장소의 코드와 최종 로컬 자율주행 소스는 버전이 다릅니다. 아래 저장소 링크는 관련 실습 코드로 구분합니다.

수동 주행에서는 Bluetooth 명령을 처리하고, 자동 주행에서는 센서 거리를 이용해 주행 방향을 판단합니다. 나머지 네 모드는 시간·동작 통계 정보를 FND에 표시합니다.

## 구현 내용

{% include project-figure.html path='/assets/img/projects/rc-car/distance-processing.png' width='3744' height='2080' alt='Trigger 출력과 Echo 인터럽트 측정에서 거리 환산·칼만 필터 보정을 거쳐 주행 판단으로 이어지는 처리 과정' caption='측정 → 거리 변환·센서별 보정 → 주행 판단의 순서로 데이터를 처리합니다.' %}

### 거리 측정

타이머·외부 인터럽트로 초음파 Echo 시간을 측정합니다.

### 데이터 처리

칼만 필터를 적용해 거리 데이터를 처리합니다.

### 주행 제어

{% include project-figure.html path='/assets/img/projects/rc-car/driving-logic.png' width='3296' height='2270' alt='근접 장애물의 후진 종료 처리, 전방 회피 판단 및 좌우 거리·변화량 기반 조향 흐름' caption='근접 장애물에서는 후진 후 해당 판단을 종료합니다. 그 외에는 전방 회피 판단에 이어 좌우 균형을 위한 조향 점수를 계산합니다.' %}

장애물 대응 주행 로직과 PWM 모터 제어를 연결합니다. 전방 20cm 미만 또는 좌우 한쪽 10cm 미만의 근접 조건에서는 후진·상태 표시 후 즉시 반환합니다.

근접 조건이 아니면 전방 거리와 감소 여부를 확인해 회전 명령을 설정한 뒤, 좌우 거리 차이와 변화량 차이에 각각 가중치 W₁과 W₂를 적용해 최종 조향을 결정합니다. 현재 코드의 설정값은 W₁=2, W₂=5입니다. 좌우 거리가 같을 때 전방 회피 단계의 명령은 우회전이며, 이어지는 조향 계산에서 이 명령이 바뀔 수 있습니다.

### 수동 주행·상태 표시

Bluetooth 모듈에서 전달하는 명령 문자를 UART1 수신 인터럽트에서 읽어 `bt_data`에 저장합니다. 메인 루프의 수동 주행 모드는 이 값을 구분해 모터 제어 함수와 FND 상태 표시 함수를 호출합니다.

#### Bluetooth 명령의 UART 파형 확인

UART의 시작 비트(0)와 정지 비트(1)를 구분한 뒤, 그 사이의 데이터 8비트를 **LSB부터 전송되는 순서**로 해석했습니다. 예를 들어 전진 그림의 `0 | 01100110 | 1`에서 가운데 데이터는 `0x66`, 문자 `f`에 해당합니다. 수신 코드가 대문자와 소문자를 모두 처리하므로 `F/f`, `S/s`, `L/l`, `R/r`은 각각 같은 동작으로 연결됩니다.

이 자료는 Bluetooth 모듈과 MCU 사이의 **UART 명령 전달을 확인한 파형**입니다. 각 명령에 따른 실제 차량 움직임은 주행 시연 자료와 구분합니다.

## 핀맵·통신 규격

| 연결 대상 | 인터페이스 | 용도 |
| --- | --- | --- |
| 초음파 센서 3개 | Trigger / Echo | 장애물 거리 측정 |
| Bluetooth 모듈 | UART | 수동 주행 명령 수신 |
| 모터 드라이버 | PWM / GPIO | 속도·방향 제어 |
| FND | GPIO | 상태 표시 |

상세 핀 번호와 전압 조건은 최종 회로·배선 확인 후 추가합니다.
