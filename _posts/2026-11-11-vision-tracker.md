## 프로젝트 개요

웹에서 선택한 인물을 카메라가 자동으로 추적하고, 게임패드로 차체를 수동 조작하는 시스템입니다. 인물 추적 좌표를 팬·틸트 명령으로 변환하여 MCU에 전달합니다.

## 담당 역할

웹 실행 환경, AI 인물 추적·재식별, 팬틸트 제어 로직과 MCU 명령 전송을 담당했습니다. 카메라와 차체 제작에도 참여했습니다.

> MCU 펌웨어는 팀원 담당입니다. 자동 제어 대상은 카메라 팬틸트이며 차체는 수동으로 이동합니다.
{: .prompt-info }

## 시스템 구조

| 순서 | 구성 요소 |
| --- | --- |
| 1 | YOLO 인물 검출 |
| 2 | BoT-SORT 추적 |
| 3 | OSNet 재식별 |
| 4 | 팬틸트 명령 전송 |

## 구현 내용

### 인물 검출·추적

YOLO 검출 결과를 BoT-SORT 추적으로 연결합니다.

### 인물 재식별

OSNet 외형 특징을 활용해 인물을 재식별합니다.

### 추적 안정화

최근 3개 검출 박스의 중앙값 필터를 적용합니다.

### 팬틸트 제어

동작 시작·정지 경계를 분리하고 각도 제한을 적용합니다.

## 핀맵·통신 규격

| 연결 대상 | 인터페이스 | 용도 |
| --- | --- | --- |
| 카메라 → Jetson | 영상 입력 | 인물 검출·추적 프레임 |
| Jetson ↔ MCU | UART | 팬틸트·차체 관련 제어 연동 |
| 사용자 → 시스템 | 웹·게임패드 | 추적 인물 선택 및 수동 이동 |

상세 핀 번호와 전압 조건은 최종 회로·배선 확인 후 추가합니다.

## 트러블슈팅

### 제어 명령 이후 모터가 움직이지 않는 문제

| 구분 | 내용 |
| --- | --- |
| 증상 | 모터 제어 명령을 보냈지만 정상적으로 구동되지 않았습니다. |
| 원인 분석 | 코드의 명령 전송 경로를 점검한 뒤 모터 인가 전압을 측정해 하드웨어 이상을 확인했습니다. |
| 조치 | 모터를 교체했습니다. |
| 확인 결과 | 교체 후 모터 구동을 확인했습니다. 모터 내부의 상세 고장 원인은 단정하지 않습니다. |

## 검증·시연

카메라 자동 추적과 차체 수동 조작을 구분해 시스템을 설명합니다. FPS·정확도·지연 수치는 측정 조건과 기록을 확보한 뒤 추가할 예정입니다.
