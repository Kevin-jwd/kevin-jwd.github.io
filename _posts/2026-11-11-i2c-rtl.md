## 프로젝트 개요

Slave FPGA에서 온습도·거리 데이터를 수집하고, Master FPGA가 I2C로 읽어 FND와 OLED에 표시하는 센서 모니터링 시스템입니다.

## 담당 역할

I2C Master·Slave와 센서 수집·FND·OLED 표시 등 RTL 전반을 직접 구현했습니다.

> 개별 모듈의 소스·테스트벤치와 팀 발표자료를 함께 연결해 설계 내용을 설명합니다.
{: .prompt-info }

## 시스템 구조

| 순서 | 구성 요소 |
| --- | --- |
| 1 | DHT11 / HC-SR04 |
| 2 | Slave FPGA |
| 3 | I2C |
| 4 | Master FPGA / 표시 |

## 구현 내용

### 센서 타이밍

DHT11 통신 및 HC-SR04 Trigger·Echo 측정 타이밍을 구현합니다.

### I2C 통신

두 FPGA 사이에서 센서 데이터를 전송합니다.

### 예외 처리

DHT11 체크섬·타임아웃과 초음파 Echo 대기·유지 시간 제한을 검사합니다.

### 표시·검증

FND·OLED에 데이터를 표시하고 모듈 테스트벤치와 측정 파형을 정리합니다.

## 핀맵·통신 규격

| 연결 대상 | 인터페이스 | 용도 |
| --- | --- | --- |
| FPGA ↔ FPGA | I2C | Master·Slave 센서 데이터 전송 |
| DHT11 → Slave | 센서 데이터 신호 | 온습도 데이터 및 체크섬 |
| HC-SR04 ↔ Slave | Trigger / Echo | 펄스 시간 기반 거리 측정 |
| Master → 표시 장치 | FND / OLED | 수신 센서 데이터 표시 |

상세 핀 번호와 전압 조건은 최종 회로·배선 확인 후 추가합니다.

## 트러블슈팅

문제 발생 당시의 증상과 점검 과정, 수정 내용 및 확인 결과를 정리해 추가할 예정입니다.

## 검증·시연

데이터시트의 센서 측정 타이밍과 실제 파형을 비교하고 통신·센서 모듈 테스트벤치를 작성했습니다. 구체적인 파형 이미지와 판정 기준은 해당 시험 자료를 추가해 정리할 예정입니다.
