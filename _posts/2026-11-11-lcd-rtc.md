## 프로젝트 개요

RTC의 시간을 ATmega128A에서 읽어 LCD에 표시하고 팀원의 계산기 기능과 통합한 프로젝트입니다.

## 담당 역할

GPIO 4비트 LCD 드라이버와 I2C RTC 시간 읽기·표시 기능을 담당했습니다.

> 계산기 기능은 팀원이 구현했습니다. RTC의 정확한 부품명과 핀 번호는 실제 부품·배선과 대조한 뒤 추가합니다.
{: .prompt-info }

## 시스템 구조

| 순서 | 구성 요소 |
| --- | --- |
| 1 | RTC 시간 레지스터 |
| 2 | I2C 읽기 |
| 3 | ATmega128A |
| 4 | GPIO 4비트 LCD |

## 구현 내용

### LCD 초기화·출력

GPIO 4비트 모드로 LCD를 초기화하고 문자를 출력합니다.

### RTC 시간 읽기

I2C를 통해 RTC 시간 데이터를 읽습니다.

### 주소 접근

Slave 주소와 내부 메모리 주소를 구분해 접근합니다.

### 기능 통합

시간 표시 기능을 팀원의 계산기 기능과 통합합니다.

## 핀맵·통신 규격

| 연결 대상 | 인터페이스 | 용도 |
| --- | --- | --- |
| RTC ↔ ATmega128A | I2C | 시간 레지스터 읽기 |
| ATmega128A → LCD | GPIO 4비트 | 명령·문자 데이터 출력 |

상세 핀 번호와 전압 조건은 최종 회로·배선 확인 후 추가합니다.

## 트러블슈팅

### RTC 레지스터 접근 절차 수정

| 구분 | 내용 |
| --- | --- |
| 증상 | 메모리 주소와 데이터 중심으로 작성한 전송 구조를 점검할 필요가 있었습니다. |
| 원인 분석 | RTC 데이터시트와 기존 전송 절차를 대조했습니다. |
| 조치 | Slave 주소와 내부 메모리 주소를 구분한 접근 절차로 수정했습니다. |
| 확인 결과 | 수정한 절차를 시간 읽기·표시 구현에 반영했습니다. 상세 파형과 시험 결과는 추가 정리 예정입니다. |

## 검증·시연

초기화 후 RTC의 시간을 읽어 LCD에 표시하는 흐름을 구현했습니다. 통신 파형과 실제 표시 사진을 함께 연결해 검증 내용을 보완할 예정입니다.
