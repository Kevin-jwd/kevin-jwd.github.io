안녕하세요. 임베디드 SW 개발자 **도재우**입니다.

센서 데이터 수집, MCU 제어, Linux 드라이버와 PC 프로그램을 연결한 프로젝트를 정리합니다.
각 문서에서 담당 범위, 구현 내용, 통신 구조와 문제 해결 과정을 확인할 수 있습니다.

## 개발 경험

| 분야 | 주요 경험 |
| --- | --- |
| MCU / Firmware | 타이머·인터럽트·UART·PWM을 이용한 센서·모터 제어 |
| Linux Driver | Jetson 환경의 I2C 센서·LCD 커널 드라이버 |
| HMI / Vision | Qt 차량 HMI, 얼굴 인증, 인물 추적과 팬틸트 제어 |
| FPGA / RTL | Verilog 기반 센서 수집과 I2C 통신·표시 설계 |
