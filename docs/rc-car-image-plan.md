## 이미지별 준비 기준

### 1. 실물 사진

- `IMG_5419.jpeg`: 전체 차량과 FND·MCU·초음파 배치를 함께 보여주는 우선 후보입니다.
- `IMG_5417.jpeg`: 전면의 3방향 센서를 크게 보여주는 보조 후보입니다.
- `IMG_5418.jpeg`: FND 2개를 보여주는 상세 사진 후보입니다. 화면이 꺼진 사진이므로 실제 표시 기능의 검증 사진으로 사용하지 않습니다.
- 현재 원본은 배경의 책상·키보드가 함께 보입니다. 최종 사용 시 필요하면 여백을 줄이되, 부품·배선 형태를 바꾸지 않습니다.
- 생성형 배경 제거본 대신 촬영 원본을 대표 자료로 우선 사용합니다.

### 2. 시스템 구성도

| 구분 | 넣을 요소 | 연결에 표시할 내용 |
| --- | --- | --- |
| 입력 | HC-SR04 3개 | Trigger / Echo |
| 입력 | Bluetooth 모듈 | UART1 명령 수신 |
| 입력 | 버튼 | 모드 전환 |
| 처리 | ATmega128A | 거리 측정·필터·주행 판단 |
| 구동 | L298N → DC 모터 | PWM / GPIO 방향 신호 |
| 표시 | FND 2개·LED | 상태·조회 정보 출력 |

Bluetooth 세부 모델은 한글 파일에서 HC-06, 기존 확인 기록에서는 ZS-040 보드로 적혀 있습니다.
확정 전에는 그림에 `Bluetooth 모듈`로 표시합니다. 이 확인 때문에 개요를 변경할 필요는 없습니다.

### 3. 모드 전환 FSM

기존 도식은 BTN0의 눌림·해제에 따라 6개 모드가 순환하는 구성을 보여줍니다.
하드웨어 전체 구성이나 자율주행 분기까지 한 그림에 합치지 않습니다.
조회 모드가 있다는 것과 표시값의 정확성 검증은 구분합니다.

### 4. 거리 측정·필터링

기존 상세 도식 한 장으로 측정·변환·보정을 연결할 수 있습니다.
그림의 Trigger/Echo 파형은 **원리 설명용**이며 실제 오실로스코프 측정 파형으로 소개하지 않습니다.
문서에는 Timer3 1카운트 64μs, 거리 환산 및 센서별 필터 처리 내용을 연결합니다.
실제 로그가 없다면 보정 전후 그래프나 정확도 수치는 추가하지 않습니다.

### 5. 주행 판단 흐름도

기존 파일:

- `그림/RC카_자동주행_판단로직_간소화.png`
- `그림/RC카_자동주행_판단로직_코드기준.png`
- 수정 방향 기록: `RC카_위치별_교체문구_v3.md`

현재 코드의 핵심은 다음 순서입니다.

1. 근접 장애물이 있으면 후진·표시 후 `return`합니다.
2. 근접 조건이 아니면 전방 거리·감소 여부에 따라 회전 명령을 설정합니다.
3. 2번의 조건 성립 여부와 관계없이 가중 조향 계산을 이어서 실행합니다.

따라서 전방 회피의 참 분기도 가중 조향 계산으로 이어져야 합니다.
좌우 거리가 같을 때의 회전 분기도 있으므로 단순히 ‘항상 더 넓은 쪽으로 회전’이라고만 표현하지 않습니다.
실물 사진·FSM과 달리 이 그림은 현재 코드와의 일치를 먼저 확인합니다.

### 6. 시연 영상

- 본인 차량의 영상에서 핵심 동작이 보이는 구간을 선정합니다. 파일명만으로 시연 결과를 확정하지 않습니다.
- 우선 15~30초 내외의 장애물 대응 장면을 권장하고, 필요하면 수동 조작·FND 장면을 별도로 연결합니다.
- 사용 파일, 구간, 촬영 조건, 관찰된 결과를 짧은 캡션으로 남깁니다.
- 기존 기록에 있는 S자 반복 조향이 보이면 촬영 결과로 설명하고, 수정 후 개선됐다고 덧붙이지 않습니다.
- 영상 전체를 자동재생 GIF로 바꾸기보다 사용자가 재생할 수 있는 영상 링크·플레이어를 사용합니다.
