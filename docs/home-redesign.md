## 변경 범위

- `_layouts/home.html`: 소개, RC카 구현 탐색, 실제 출력 기록, LCD 문제 해결, 분야별 프로젝트 목록.
- `assets/home.css`, `assets/home.js`: 홈 화면에만 적용하는 스타일과 인터랙션.
- `_layouts/default.html`: 홈에서만 추가 파일을 불러오는 조건과 body 클래스.
- `index.html`: 홈 페이지 제목.
- 프로젝트 기술서, 프로젝트 순서·기간·인원, 기존 문서 스타일과 사진 원본은 유지합니다.

## 콘텐츠와 동작

- RC카의 측정·통신·제어·표시 영역별 설명을 선택하며 실제 구조도·파형과 관련 프로젝트를 확인합니다.
- 출력 GIF는 명시적으로 재생할 때만 불러오며, 종료·구현 화면 전환·탭 비활성화 시 제거합니다. 실제 주행 시연으로 소개하지 않습니다.
- LCD 문제 해결은 스마트 선풍기 기술서에 기록된 400kHz → 100kHz 버스 분리 사례를 사용합니다.
- 프로젝트는 기존 최신순을 유지하며 분야 필터로 일부만 표시합니다. 필터를 선택해도 프로젝트 번호는 유지합니다.
- JavaScript를 사용하지 못해도 기본 설명과 모든 프로젝트 링크를 읽을 수 있습니다.

## 확인 범위

- Liquid 호환 렌더링, 7개 프로젝트 데이터, 이미지 파일·링크 대상, 고유 ID·aria-controls 확인.
- DOM 환경에서 영역 전환, 분야 필터, 출력 GIF 선택·재생·종료·오류 복구, 기존 검색·테마 기능 확인.
- 로컬 환경에 Ruby/Jekyll이 없어 정식 빌드는 수행하지 못했습니다. GitHub Pages의 기존 빌드 워크플로로 최종 확인합니다.
- 브라우저 연결 오류로 실제 화면의 시각 점검은 수행하지 못했습니다.
