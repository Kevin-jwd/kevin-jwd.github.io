그 외 프로젝트는 주요 프로젝트 아래에 유지합니다. 번호는 GitHub 프로필과 사이트에서 동일하게 사용합니다.

## 근거

- 기간·주요 프로젝트 범위: `도재우_이력서 및 포트폴리오_v2.0.0.hwp`의 프로젝트 기술서 6건.
- 참여 인원: GitHub 프로필 `Kevin-jwd/Kevin-jwd/README.md`의 기존 프로젝트별 기록. 한글 기술서에는 별도 인원 값이 없습니다.
- RC카는 개별 구현과 공동 발표를 구분합니다. 공동 발표 인원을 차량 구현 인원에 합산하지 않습니다.
- IMU의 세부 기간은 한글 기술서와 기존 README에서 확인되지 않아 임의로 채우지 않습니다.
- RC카와 LCD·RTC 저장소의 존재·기본 브랜치를 GitHub에서 확인하고 전용 저장소 링크로 갱신했습니다.

## 수정 위치

- `_data/project_order.json`: 전체 표시 순서
- `_posts/*.md`: `project_number`, `period`, `people`, `project_type`
- `content/projects.json`: 이전 메타데이터 보관본도 동일하게 동기화

사이트 게시일 `date`는 프로젝트 수행기간으로 바꾸지 않습니다. 기존 프로젝트 URL도 유지합니다.
